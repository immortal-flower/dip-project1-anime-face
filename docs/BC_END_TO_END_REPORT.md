# B冻结检测器 + C关键点回归联合测试

## 测试目的

本实验把B同学冻结的动漫人脸检测器与C同学最终的28点关键点模型串联起来，验证“输入图片 → 检测人脸框 → 回归28点”的真实端到端流程。测试时间为2026-09-28。

## 固定输入与协议

- 测试集：C固定划分中的38张AnimeFace裁剪图，关键点已人工复核，每张图含一个真值脸框。
- 检测器：`deliverables/b-final-model.zip` 恢复出的B冻结模型，评价期间不再调阈值。
- 关键点模型：C最终HOG与形状回归各50%融合模型。
- 匹配规则：检测框与真值框IoU≥0.5，一对一匹配。
- 关键点指标：只在匹配成功的框内计算可见点NME和PCK；漏检保留为FN。
- 端到端成功：图片成功匹配人脸框，并且该脸的NME≤0.10。

B检测框下的关键点指标只有3个匹配样本、80个可见点，样本太少，不能单独代表关键点模型总体能力。完整端到端成功率同时考虑了35张漏检，更能反映当前系统实际表现。

## 结论

B、C模型已经通过统一接口真实连通。人工真值框下，C模型平均NME为0.0864；换成B检测框后，仅3/38张图片匹配成功，说明当前端到端系统的主要问题是检测器漏检。第二个匹配样本的框IoU只有0.5289，NME升至0.2320，也说明框位置偏差会进一步放大关键点误差。

B原报告的108页Manga109整页test Recall为4.83%，本实验在38张AnimeFace裁剪图上的Recall为7.89%。两者图像类型和尺度不同，应分别报告，不能合并成同一个检测结论。
