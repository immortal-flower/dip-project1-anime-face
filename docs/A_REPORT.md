# A 部分报告初稿：数据准备与十一通道

本报告记录当前实际完成的数据与特征实验，不包含尚未进行的真实检测／关键点评价。数据版本与命令见 [A_WORK_LOG.md](A_WORK_LOG.md)，六图详细观察见 [CHANNEL_EXPERIMENT.md](CHANNEL_EXPERIMENT.md)。

## 数据与划分

从Manga109的109本漫画中选择654个有标注内页，按可识别系列归成104组。先固定训练、验证、测试来源，再采样区域，种子为42。采用按组近似75/10/15，避免同原图的不同裁剪进入不同集合。

原始版本共有2536正例与3924负例。正例依据XML人脸框，负例来自真实漫画背景，避让向四周扩展15%后的全部已知人脸标注，并在原尺寸过滤低纹理。新版本对正例每侧默认扩10%，碰到新邻脸时减小比例，最后缩到24×24。10%是初始可调策略，不是老师规定或通过测试集调出的最优值。

`source_gt_bbox`保留原始人脸真值，`source_bbox`为实际裁剪框，`bbox`为24×24样本窗口。654个整页真值未随扩边变化。现有框可能本身与邻脸交叠，或原XML没有标出画中画的人脸，因此几何检查不能替代质量验收。

实际抽查68张来源分层样本，隔离14张明显侧脸／局部脸／无五官正例及4张含脸或疑似含脸负例；另按缩小后标准差过滤35张低纹理背景。候选清单保留6407张，标签和所属集合不变，剩余图片仍待复核。该抽查不能估计总体错误率，也不能据此宣称全部图片已干净。

## 十一通道的定义

定义文件为 `configs/feature_definition.json`，版本 `dip11-int-v1`。C0为灰度，C1为2×2均值，C2在C1上按2像素间隔再平滑；C3～C6在C1上计算短距离水平、垂直、两种对角差，C7～C10在C2上计算长距离差。

四值整数均值采用 `floor((a+b+c+d+2)/4)`。差值d通过 `floor((d+255)/2)` 映射到uint8，零差分编码为127。中间使用int32避免溢出，无法完整计算的右／下边界补0。当前24×24检测窗口中，各通道共同有效采样区为左上17×17。

## 为什么平滑能抑制部分噪声

将观测值写为 `I = S + n`，S为信号、n为噪声。如果一个2×2区域的四个噪声互不相关、均值为0、方差为σ²，则平均噪声的方差为：

`Var((n1+n2+n3+n4)/4) = 4σ²/16 = σ²/4`。

因此平滑在信号变化缓慢处能减弱独立噪声。但边缘两侧也会被平均，小眼睛、细发丝会变模糊；相关噪声、网点和真实纹理不能直接套用独立噪声假设。整数取整也会引入小量误差。

受控实验使用512×512常量128叠加标准差20的高斯噪声，固定种子42。有效区C0、C1、C2的方差比例实际为 **1 : 0.2510 : 0.0634**，与这个平坦区域下均值抑噪的预期一致。该输入为机理演示的合成噪声，不是检测负样本。

## 为什么像素差有一定亮度鲁棒性

若所有像素同时增加同一个常量b，且不发生饱和，则：

`(I(p1)+b) - (I(p2)+b) = I(p1)-I(p2)`。

所以整体偏亮／偏暗时相对明暗关系可能保持。固定规则的整数平滑对整数亮度平移也保持此性质。受控实验中，像素取20～179并整体加30，C3～C10最大差全部为 **0**。

这不意味着对所有光照变化都不变。强行加150再截断到255会饱和，实际梯度最大变化为 **30**；对比度缩放会放大或缩小差分，局部阴影也会改变两处亮度差。因此需使用来自不同画风、亮度和遮挡条件的真实数据。

## 六张图像的观察与数值对照

已使用两张真实人像、两张近正面动漫脸、一张头发遮挡脸、一张复杂漫画页。新版拼图第一格保留原始颜色，C0为实际灰度输入，所有通道保持原值显示。

眼睑和眉嘴的上下明暗在垂直差分中较明显；脸侧和鼻部左右变化在水平差分中较明显；斜向轮廓与头发也会在对角差分中响应。长距离差分保留更粗的结构，但小图中的细节容易丢失。复杂漫画中的分镜边界、对白与建筑同样有强响应，说明一条边缘不足以判断人脸，需要B从位置关系中选择多条弱特征并组合。

整数与float32同取整版本在六图所有通道中完全一致；不取整float32与整数版的有效区最大差为1.21875。两个版本的局部计时保存在各轮measurements.json，不将不同环境和图像尺寸的数字混在一起，也不据Python/NumPy计时宣称MCU整数实现一定更快。本轮未证明真实检测框或NME在两种通道下相同。

## 近似重复与数据质量限制

AnimeFace最初63565张图片包含22043个完全相同像素副本，剩下41522张唯一像素图。进一步筛出1564对感知相似候选；本轮前24对视觉高度相似。应先与C数据清单对接再决定固定分组，不能把不同文件名当作独立图片。

Manga109跨集合筛出812对候选，前24对主要为相似直线／分镜边缘，不能因相似指纹就推断同来源泄漏。简单图案重复、压缩差异、裁剪变化都需要结合源页观察。当前筛查并不穷尽旋转、镜像或任意裁剪的近似重复。

## 评价与交付

检测评价使用原图坐标，IoU≥0.5，预测按分数逐图一对一匹配。汇总TP/FP/FN后计算Precision、Recall、F1，重复检测算FP，缺失预测页按空检测计入并显式列出。最终评价前要核对疑似漏标来源页，并与B确定近正面目标和全XML真值的关系。当前没有真实检测指标，不填写虚构结果表。

独立Python3.10环境已通过16项测试和合成端到端验证，环境日志和页面截图可复核。阶段包包含A的数据清单、24×24图、通道结果、定义、代码和记录；C标注、真实模型、完整原图库和最终课程报告整合仍是后续工作。
