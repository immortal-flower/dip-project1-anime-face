## 不依赖 C、仍应完成的工作

### 1. 样本复核与类型覆盖记录

PDF 第 3 页明确提出正样本覆盖脸型、眼型、发型、轻微旋转、绘制风格和少量遮挡。当前随机选取每页最多四张、只按尺寸筛选，没有类别覆盖表，也没有正式筛查严重侧脸、过度倾斜和不完整裁剪。

负样本来自正确的真实场景，但未统计文字框、头发、衣服、手部、建筑等是否有足够代表例子；随机抽样不能证明每类已经覆盖。当前 6,460 条 `review_status` 全为 `needs_review`，没有 `decisions.csv` 或已复核清单。35 张低纹理只是自动筛出的提示，不是全部待复核工作。

建议完成：明确合格标准，三人按约定分担复核，记录姿态／遮挡／背景类别，展示有来源的代表例子，导出保持原 split 的已接受清单和筛选前后数量。复核应在训练调参前按统一标准进行，不能根据测试误差选择性删除难样本。老师未明确要求每张训练图逐张人工审核，但当前缺少质量验收证据，不能把待复核初稿当作最终数据。

### 2. 正样本“适度扩展边界”尚未实现

详细说明 §10.1 给出“人脸框 → 适度扩展边界 → 裁剪 → 24×24”的流程。现有 `prepare_manga_detection_data.py` 直接裁 XML 框，没有可配置的正样本扩边。XML 最大坐标加 1 只是坐标约定转换；负样本避让人脸的 15% 也不是正样本扩边。

建议补上可配置扩边，并可视化比较裁剪前后是否保住额头／下颌、是否带入邻脸。老师没有指定比例，不应虚构固定比例要求。新版本沿用已有来源划分；原始真值框与扩展裁剪框分开保存，不能为了扩边把评估真值一起放大。

### 3. 近似重复与语义同系列仍待检查

Manga109 当前按书／`volNN` 后缀归组，做了裁剪像素完全重复检查；AnimeFace 已有完全重复清单。尚未检查近似重复（压缩、缩放、轻微裁剪）以及不同名字但实际同系列的情况。这是团队为落实防泄漏承诺的补充检查，不能将其表述为老师指定了某种去重算法。

可先在现有 Manga109 和 AnimeFace 图片上生成疑似重复候选及归组问题表，无需 28 点标注；涉及 C 既有 split 的修正待实际清单到位后协商。疑似相似不是自动认定重复，不应静默重新随机划分。

### 4. 环境复现证据

PDF 环境步骤和详细说明 §8.4 要求 uv 环境搭建及环境截图。当前仓库无 `.venv/pyvenv.cfg`，本轮命令搜索未发现 PATH 中的 uv；不能据此断言电脑从未安装过 uv。已验证环境为 Python 3.9、NumPy 1.20.3，与 README 的 Python 3.10 及 `numpy>=1.24` 不一致。

需按 README 在隔离环境中实际安装并运行测试及 A 的示例，记录 Python／依赖版本、uv 版本和真实成功输出截图。已有测试通过证明当前环境可用，不证明新电脑按 README 一定复现成功。无需为凑老师建议的依赖列表而导入根本没用的库。

### 5. 特征原理的报告说明与最终归档

PDF 第 2 页要求能解释“平滑为何抑制噪声、像素差为何有一定亮度鲁棒性”。现有报告有观察、测试有整体加亮不变验证，但建议补上明确的公式解释及限制：局部均值会平均部分随机扰动，也会损失细节；两处都加相同亮度时差值抵消，但饱和裁剪、对比度变化、非均匀光照不保证不变。

老师要求最终保存 11 通道定义及固定划分／种子，并交报告和实际通道图。现有代码、接口文档和本地清单已经包含大部分定义；最终模型包还没有和 B 对齐版本、取整、边界与通道来源。无需强制采用建议的 `feature_definition.json` 文件名，但加载模型时应能明确识别所用定义。

通道 PNG、输入图、测量 JSON 和数据清单都在忽略目录，只克隆 GitHub 不会取得它们。需要列明团队获取／复现办法，整理 A 的报告章节与提交目录，实际检查包内图片、清单和定义是否齐全；这不意味着应把 Manga109 原图直接推到公开仓库。

## 不应误列为 A 的必做遗漏

- 数据增强：老师要求“只允许作用于训练集”，没有说必须使用增强。可通过真实样本覆盖轻微旋转；不足时再增加训练增强。
- 比较至少三种特征策略：详细说明第十五节为“可选”探究，不是 A 基础验收门槛。
- 与参考工程逐位相同：现有取整策略公开记录；老师要求参考并实现通道，没有明确要求与外部工程逐位相同。应如实说明差异，不能把本项目浮点一致性当成外部对齐证明。
- 所有图提前缓存十一通道：训练／推理时调用函数即可，不强制存储全量通道图片。
- 独自完成 B 的模型、困难负样本挖掘或 C 的 28 点训练：不是 A 的独立工作；A 负责接口配合，人工复核由团队分担。

优先顺序：正样本裁剪策略与质量标准 → 复核和覆盖记录、近似重复检查 → 冻结第一版可交付数据 → 环境复现及 A 报告／导出资料 → 与 B 联合真实评价。C 的实际标注清单可以并行等待，不阻塞前面几项。
