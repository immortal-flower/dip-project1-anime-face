## 基础版限制

- 随机候选池和阈值搜索较小，逐窗口 Python 扫描较慢，不保证真实检测效果与速度。
- 弱树最大深度为 2，纯类别分支可能提前成为叶子。固定三个判断节点的导出表达可由 B 后续完善。
- 每级目标可能在指定弱树上限内无法同时满足；此时模型会记录 `best_available_within_limit`，真实报告必须如实披露。
- 后续全量困难负样本候选仍需同学确认；弱模型的全页扫描较慢，正式运行必须记录步长、尺度、NMS 前截断和实际页面覆盖。
- 关键点每点仅两对局部采样，三级回归，没有多初始化；真实点序仍需确定。
- 真实数据版本、完整超参数记录和模型说明待补。

后续更新应区分代码实现、合成验证、真实实验，并记录证据。
