# 进度与验证记录

## 2026-09-27：C模块 Fern/LBF 进阶实现

- 新增完整可运行的 Fern/LBF 风格级联回归：每个关键点周围进行形状索引像素差测试，Fern 二值编码选择叶节点，所有叶节点组成 LBF one-hot 特征，再用 Ridge 预测 56 维形状更新。
- 损失显式使用 `visibility × landmark_weights`；现有人工数据中绿色/红色对应 1/0，也支持 0～1 连续置信度。加入官方左右点对映射的水平翻转增强，并接入统一 `LandmarkRegressor` 和 Demo。
- 仅依据验证集从 8 组配置中选出 3 Fern/点、深度4、4级、Ridge=10、学习率0.5、半径0.12；train/val NME 为0.0142/0.0920。选定后一次性评价人工test，平均/中位NME为0.1050/0.0925（37张双眼归一化，1张框对角线回退）。
- Fern/LBF在当前190张监督训练图上过拟合，未超过HOG+基础形状融合的test NME 0.0864，因此作为进阶实现和对比模型保留，正式Demo仍采用验证集更优的融合模型。
- 15项单元测试通过，包含连续权重、缺失点权重拒绝、模型保存/加载和统一多框推理。

- 测试集38张均为人工真值；37张使用双眼中心距离归一化，1张回退检测框对角线。测试集在训练、调参和人工训练/验证修正过程中保持不变。

## 基础版限制

- 随机候选池和阈值搜索较小，逐窗口 Python 扫描较慢，不保证真实检测效果与速度。
- 弱树最大深度为 2，纯类别分支可能提前成为叶子。固定三个判断节点的导出表达可由 B 后续完善。
- 微型样例负样本耗尽后会重用完整训练池，并记录 reused_training_pool；可能产生重复阶段，不等价于困难负样本挖掘，正式训练需替换此回退。
- 阈值保留当前验证正样本，尚无目标误报率控制。
- 关键点每点仅两对局部采样，三级回归，没有多初始化；真实点序仍需确定。
- 真实数据版本、完整超参数记录和模型说明待补。

后续更新应区分代码实现、合成验证、真实实验，并记录证据。
