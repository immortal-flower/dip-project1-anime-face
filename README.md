# dip-project1-anime-face
数字图像处理项目一：基于特征工程的动漫人脸检测与关键点回归（团队作业）

本仓库用于保存项目要求、团队代码和后续运行说明。目前仅整理项目要求文档，尚未实现项目代码。

## 项目要求

以下文件由老师提供，保留原始内容，作为项目实现与验收的依据：

- [项目一 PDF](docs/项目一%20基于特征工程的动漫人脸检测与关键点回归.pdf)
- [项目一详细说明（Markdown）](docs/项目一_基于特征工程的动漫人脸检测与关键点回归_详细说明.md)

## 团队协作

成员接受仓库协作邀请后，可将仓库克隆到本地：

```bash
git clone git@github.com:immortal-flower/dip-project1-anime-face.git
```

使用 SSH 地址需要在 GitHub 账户中配置本机的 SSH 公钥；也可以从仓库的 Code 菜单复制 HTTPS 地址。

建议每项任务使用独立分支，通过 Pull Request 合并到 main。修改代码框架或运行方式时，请在同一次提交中更新 README。
